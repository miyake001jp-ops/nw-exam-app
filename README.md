# ネットワークスペシャリスト 午前II 合格対策 Webアプリ

令和8年度（2026年度）ネットワークスペシャリスト試験（科目A-2：午前II）合格のための学習Webアプリケーションです。

## 特徴
- **過去15回分（平成21年〜令和7年）の過去問完全網羅**
- **過去問の同一問題（再出題）の相互リンク＆出題履歴表示**
- **7つの学習モード**（通常学習、本番テスト、弱点克服、頻出問題、予想問題など）
- **詳細な統計分析**（年度別再出題率、頻出ランキング、分野別レーダーチャート）
- **令和8年度最新予想問題（25問）**（HTTP/3, QUIC, TLS 1.3, ゼロトラスト, Wi-Fi 6E/7, SRv6等）
- **スマホ対応（PWA）＆ オフライン動作可能**
- **端末間データ同期**（QRコード読み取りで一瞬でPCからスマホへ履歴同期）

## 使い方
ブラウザでそのまま開くだけで利用可能です。
スマホのChromeで「ホーム画面に追加」または「アプリをインストール」すると、ネイティブアプリのように使えます。
